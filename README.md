# PyGRID

PyGRID is an open-source Python toolkit for constructing Eclipse-style
corner-point reservoir grids directly from interpreted geological data.

Features

✓ Top structure maps

✓ Bottom structure maps

✓ Thickness maps

✓ Fault traces

✓ Automatic fault throw

✓ Corner-point grid generation

✓ GRDECL export

✓ GRID-compatible runfiles

✓ tNavigator support

Designed as a modern replacement for legacy GRID workflows.
